1. ARSITEKTUR & STACK TEKNOLOGI YANG DIGUNAKAN
--------------------------------------------------------------------------------
Arunaki menggunakan arsitektur Desktop Hybrid Native Rust (setara standar aplikasi
desktop modern seperti LM Studio, Ollama UI, dan Docker Desktop):

A. Desktop Shell (Tauri v2) — [src-tauri]
   - Crate: tauri v2.12.5, tauri-plugin-notification v2, tauri-plugin-log v2
   - Rendering Engine: Microsoft Edge WebView2 (Windows Native)
   - Fungsi:
     * Menyediakan container window native Windows yang ringan dan cepat.
     * System Tray Icon di taskbar dekat jam dengan menu: "Open Arunaki" & "Quit".
     * Windows Action Center Toast Notification: Notifikasi native Windows dengan
       suara chime saat AI selesai memproses tugas dokumen/pembukuan.
     * Packaging Installer resmi Windows (.exe setup NSIS dan .msi WiX) via `tauri build`.

B. AI Engine & Daemon Server — [core/arunaki-engine]
   - Framework: Axum v0.7 + Tokio v1.40 (Multi-threaded Async Runtime)
   - Arsitektur: Modular Library (`arunaki_engine` di src/lib.rs) + Standalone Daemon (src/main.rs)
   - Port Default: http://127.0.0.1:4096 (fallback dinamis ke port 0 jika bentrok)
   - Endpoint:
     * `/api/*`: REST API sesi, history, file explorer, workspace memory, tools.
     * `/api/event`: Server-Sent Events (SSE) streaming token AI real-time.
     * `/api/desktop/engine-info`: Metadata runtime dinamis (versi, port, OS, framework).

C. Local-CLI Bridge Server — [core/arunaki-engine/src/bridge]
   - Port Default: http://127.0.0.1:20188/v1/chat/completions (OpenAI-compatible)
   - Fungsi: Jembatan lokal agar tool developer (Cursor IDE, Claude Code CLI, Python,
     VSCode extension) bisa langsung memakai model AI Arunaki tanpa server perantara luar.
   - Proteksi Anti-Bentrok & Keamanan:
     * Smart Probing: Cek apakah instance Arunaki lain sudah aktif; jika ya, instance baru
       langsung memakai bridge yang sudah ada (tidak akan crash/error).
     * Incremental Fallback: Jika port 20188 terpakai software lain, otomatis pindah ke
       20189, 20190, atau port bebas OS, lalu mencatatnya ke `~/.arunaki/bridge-info.json`.
     * Origin Guard: Menolak request cross-site dari tab browser website luar (403 Forbidden)
       untuk mencegah pencurian kuota AI, namun tetap mengizinkan tool CLI dan Arunaki.

D. Document & COM Sidecar — [core/arunaki-docs]
   - Binary: arunaki-docs.exe (Native Rust Win32 COM)
   - Fungsi: Automasi dan ekstraksi tabel dokumen Microsoft Excel (.xlsx) dan Word (.docx)
     langsung di level OS tanpa dependensi Python atau Node.js.

E. Web Frontend Workstation — [apps]
   - Framework: React 19, TypeScript ~5.8, Vite 6, Tailwind CSS 4, TanStack Query 5
   - Iconography: 100% SVG Vector Icons (Lucide React) — ZERO Emojis.
   - Theme: Strict Monochrome palette dengan aksen oranye gelap kaya (#cf6613).


2. CARA PENGERJAAN & LANGKAH-LANGKAH IMPLEMENTASI
--------------------------------------------------------------------------------
1. Modularisasi Engine (`core/arunaki-engine`):
   - Membuat `core/arunaki-engine/src/lib.rs` yang mengekspor fungsi `init_engine_and_bind`
     dan `run_axum_server`.
   - Mengubah `core/arunaki-engine/src/main.rs` agar mengimpor dari modul `arunaki_engine`,
     sehingga binary daemon CLI tetap berjalan 100% seperti semula.

2. Inisialisasi & Konfigurasi Tauri v2 (`src-tauri`):
   - Mendaftarkan crate `src-tauri` ke workspace root `Cargo.toml`.
   - Menghubungkan dependensi `arunaki-engine = { path = "../core/arunaki-engine" }`.
   - Mengonfigurasi `src-tauri/tauri.conf.json`:
     * Identifier: "com.arunaki.desktop"
     * Title: "Arunaki" (Ukuran window 1280x820, min 960x600, Dark theme)
     * Frontend dist: "../apps/dist", Dev URL: "http://localhost:5173"

3. Background Engine Spawning di Setup Hook:
   - Pada `src-tauri/src/lib.rs`, saat aplikasi desktop dibuka, thread background Tokio
     otomatis menjalankan engine Axum & Local-CLI Bridge.
   - Mendaftarkan System Tray Icon dengan opsi "Open Arunaki" dan "Quit".

4. Proteksi Port & Origin Guard pada Local Bridge (`bridge/mod.rs`):
   - Menambahkan pengecekan kesehatan sebelum binding (`GET /health`).
   - Menambahkan middleware `origin_guard_middleware` yang memfilter header `Origin`.
   - Menulis port aktif secara dinamis ke file `~/.arunaki/bridge-info.json`.

5. Integrasi Notifikasi Windows Action Center (`chatDiagnostics.ts`):
   - Memasang package `@tauri-apps/api` dan `@tauri-apps/plugin-notification` di frontend.
   - Mengganti pemanggilan webview notification lama dengan API native `sendNotification`.
   - Saat tugas AI selesai, notifikasi Windows Toast resmi akan muncul dengan chime sistem.

6. Anti-Hardcode & Deteksi Sistem Dinamis:
   - File `engine-info.json` menyimpan framework aktif (`Axum v0.7 + Tokio v1.40`,
     `Tauri v2 + WebView2`, versi OS, arsitektur CPU).
   - Dialog "About Arunaki" (`AboutArunakiModal.tsx`) mengambil data langsung via API
     `/api/desktop/engine-info` saat dibuka, sehingga jika ada pembaruan versi, dialog
     langsung menampilkannya secara otomatis tanpa edit manual kode.
   - Menghapus seluruh baris lama yang menampilkan "unavailable (pure-rust)".

7. Pembersihan Total Emoji ke Ikon SVG Vektor:
   - Mengganti seluruh emoji UI (📎, ⚠️, 🟢, 📋, ✨, 🧾) dengan ikon SVG vektor Lucide:
     * `ReceiptText` untuk struk/invoice kasir.
     * `ShoppingBag` untuk pesanan penjualan/order.
     * `PanelsTopLeft` untuk kanvas dokumen.
     * `AlertTriangle` untuk peringatan konteks.
     * Dot putih monochrome untuk status "Live Connected".
   - Menambahkan regex filter emoji (`EMOJI_REGEX`) pada pembersih judul kanvas dan sesi
     agar emoji dari teks mentah/LLM tidak mengotori sidebar.
   - Menambahkan aturan ketat `STRICT NO-EMOJI RULE` pada system prompt AI (`prompt.rs`).
