1. APA ITU ARTCRAFT APPS & 4 APLIKASI DOKUMEN YANG DIPAKAI
--------------------------------------------------------------------------------
ArtCraft (https://getartcraft.com/apps, dikembangkan oleh organisasi 'storytold')
adalah ekosistem aplikasi desktop kreatif dan produktivitas native yang ditulis
DARI NOL MENGGUNAKAN MURNI RUST. Dibangun sebagai alternatif open-source, cepat,
dan offline-first untuk menggantikan software langganan Adobe dan Microsoft Office.

Dalam misi Arunaki sebagai "Desktop Computer Use Agent untuk Dokumen", 4 aplikasi
dokumen utama dari ArtCraft yang diadopsi dan diintegrasikan adalah:

1. GRIDCRAFT (Alternatif Microsoft Excel dalam Pure Rust)
   - Format: .xlsx, .csv, format tabel spreadsheet
   - Peran di Arunaki: Mengelola pembukuan, jurnal kas, kalkulasi stok, dan formula
     rekap keuangan secara otomatis dari data mentah/chat WhatsApp.

2. WORDCRAFT (Alternatif Microsoft Word dalam Pure Rust)
   - Format: .docx, rich document layout, paragraf dan tabel laporan
   - Peran di Arunaki: Menghasilkan dokumen laporan harian, surat resmi, kontrak,
     dan nota dinas yang rapi secara otonom.

3. PDFCRAFT (Alternatif Adobe Acrobat dalam Pure Rust)
   - Format: .pdf (dokumen portable, faktur cetak, rekening koran)
   - Peran di Arunaki: Membaca, mengekstrak isi tabel/teks, dan menganalisis
     dokumen PDF tagihan/invoice tanpa mengirim data ke server cloud pihak ketiga.

4. DECKCRAFT (Alternatif Microsoft PowerPoint dalam Pure Rust)
   - Format: .pptx, slide decks, materi presentasi
   - Peran di Arunaki: Menyusun ringkasan eksekutif dan deck presentasi laporan
     kinerja bulanan secara otomatis berdasarkan dokumen yang ada di folder proyek.


2. KORELASI DENGAN MISI ARUNAKI (AGENTS.md & BOUNDARIES.md)
--------------------------------------------------------------------------------
- Sesuai prinsip AGENTS.md: Arunaki setara dengan Claude Computer Use / OpenClaw
  tetapi DIBATASI 100% PADA FOLDER WORKSPACE dan berfokus pada DOKUMEN.
- Filosofi ArtCraft (Pure Rust, Native Performance, Offline-First, Zero Cloud Tether)
  sejalan 100% dengan Arunaki yang menghilangkan Electron/Node.js di runtime inti
  dan beralih ke Tauri v2 + Axum Engine.


3. CARA PENGERJAAN & IMPLEMENTASI TEKNIS DI ARUNAKI
--------------------------------------------------------------------------------

A. Implementasi GridCraft (Spreadsheet & Kalkulasi Data)
   - Modul Backend Rust: `core/arunaki-docs` dan `core/arunaki-engine/src/tool/doc_com.rs`.
   - Cara Kerja:
     1. Agent menerima instruksi minimal (misal: "Rekap penjualan ini ke excel").
     2. Modul Rust membaca struktur file Excel (.xlsx) dengan zero overhead.
     3. Sistem menjalankan formula otomatis (SUM, AVERAGE, Pajak PPh) dan menulis
        data ke cell target.
     4. Frontend menampilkan preview spreadsheet interaktif via `SpreadsheetViewer.tsx`
        lengkap dengan fitur filter dan formatting monokrom bersih.

B. Implementasi WordCraft (Word Processing & Laporan Resmi)
   - Modul Backend Rust: `core/arunaki-docs` (Win32 COM Sidecar) dan `files.rs`.
   - Cara Kerja:
     1. Membaca dan menulis dokumen Word (.docx) berbasis XML Office Open XML.
     2. Di workstation chat, AI memformat output ke dalam block [CANVAS]...[/CANVAS].
     3. Sistem secara otomatis membuat tab dokumen di editor tengah (CenterEditorView)
        dengan tipografi rapi, heading yang tepat, dan tabel data.
     4. Mengeliminasi seluruh emoji dari judul dan isi dokumen (100% SVG Vector).

C. Implementasi PdfCraft (Ekstraksi & Analisis PDF)
   - Modul Backend Rust: Parser engine `core/arunaki-docs/src/lib.rs`.
   - Cara Kerja:
     1. Memetakan karakter selectable text dan koordinat bounding box di dalam PDF.
     2. Mengekstrak tabel transaksi atau rincian rekening koran ke memori agent.
     3. Agent mengevaluasi data tanpa perlu melakukan OCR eksternal yang lambat.
     4. Seluruh parsing PDF berjalan strictly offline di memori lokal komputer pengguna.

D. Implementasi DeckCraft (Slide Decks & Presentasi)
   - Cara Kerja:
     1. Mengambil inti dari laporan atau data spreadsheet yang baru saja dibuat.
     2. Membagi materi ke dalam struktur kartu slide (Judul, Poin Inti, Metrik Angka).
     3. Menyiapkan layout presentasi visual yang siap diekspor ke format dokumen slide.

E. Shell Pembungkus Desktop (Tauri v2 + Axum)
   - Menggunakan Tauri v2 (`src-tauri`) untuk membungkus antarmuka web dan memanggil
     engine backend Rust Axum di port lokal 4096.
   - Menggunakan Windows Action Center Toast Notification bawaan OS saat pekerjaan selesai.
   - Menghubungkan System Tray icon dan installer resmi Windows (.msi / setup.exe).


4. BAGIAN-BAGIAN PENGUJIAN (TEST SUITES & VERIFIKASI)
--------------------------------------------------------------------------------
Untuk memastikan integrasi 4 aplikasi dokumen ini bekerja tanpa bug, pengujian
dibagi menjadi beberapa lapisan:

--------------------------------------------------------------------------------
TEST LAYER 1: UNIT TEST RUST ENGINE & SIDECAR (15/15 PASSED)
--------------------------------------------------------------------------------
Jalankan perintah:
  cargo test --workspace

Cakupan Pengujian:
1. `core/arunaki-docs` (Pengujian Format Dokumen Office):
   - `tests::cell_ref_roundtrip` -> Validasi konversi koordinat cell Excel (misal: A1, B12).
   - `tests::csv_excel_map_extracts_cells_and_range` -> Validasi pemetaan range spreadsheet.
   - `tests::pdf_map_extracts_selectable_text` -> Validasi parsing teks dari file PDF.
   - `tests::word_xml_extracts_paragraphs_and_tables` -> Validasi ekstraksi paragraf & tabel Word.
   - `tests::com_scripts_generate_expected_powershell` -> Validasi script native automasi OS.

2. `core/arunaki-engine` (Pengujian AI Tooling & Sandbox Security):
   - `tool::doc_com::tests::test_cell_coord_parsing_and_conversion` -> Parsing koordinat cell.
   - `tool::doc_com::tests::test_parse_cells_arg_rows_2d_array` -> Parsing baris tabel 2 dimensi.
   - `tool::doc_com::tests::test_parse_cells_arg_array_of_objects` -> Parsing array objek data tabel.
   - `paths::tests::test_contains_path_isolation` -> KEAMANAN MUTLAK: Memastikan agent TIDAK BISA
     membaca/menulis file di luar folder aktif proyek (Sandbox Boundary).
   - `session::prompt::tests::test_derive_session_title` -> Pembersihan judul otomatis & filter emoji.
   - `tool::zen::tests::*` -> 5 test transaksi ritel & void order atomic rollback.
