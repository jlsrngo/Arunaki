- Browse a website using a real headless browser (Puppeteer) with full JavaScript execution
- Unlike webfetch, this tool renders pages like a real user and can interact with dynamic content
- Automatically clicks buttons, expands modals, and loads JavaScript-rendered data
- Best used for e-commerce sites, dashboards, and SPAs where data loads dynamically
- AUTOMATICALLY detects and clicks common e-commerce buttons like "Pesanan Grosir", "Wholesale", "Show Stock", "Load More", "Lihat Semua" to reveal hidden stock/pricing data

Usage notes:
  - PREFER this tool over webfetch when browsing e-commerce sites, product pages, or any site that uses JavaScript to render content
  - The tool automatically discovers and clicks interactive elements that reveal hidden data (stock tables, wholesale pricing, expanded details)
  - You can also manually specify a button to click via click_text parameter for non-standard buttons
  - Provide a search_query to search within the website (finds search inputs and types the query)
  - Returns the full rendered page content as Markdown, including any data revealed by auto-clicking
  - Timeout is 45 seconds by default to allow for page rendering
  - This tool is read-only and does not submit forms or make purchases
