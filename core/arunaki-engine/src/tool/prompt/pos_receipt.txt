Print a customer sales receipt to a physical POS thermal receipt printer (58mm or 80mm paper) via ArunakiZen.

Capabilities:
- Formats store name, address, contact phone, invoice header, transaction item breakdown, total, amount tendered, and change.
- Optionally triggers an automatic kick signal to open the physical cash drawer upon receipt completion.
- Dispatches formatted ESC/POS printer byte streams to local Windows printer spoolers.

When to use:
- The user asks to print or re-print a receipt for a completed transaction (e.g. "print receipt for invoice R43-231026001", "print the last receipt").

Parameters:
- `invoice`: Required official invoice number (e.g. 'R43-231026001').
- `open_drawer`: Boolean flag indicating whether to kick the physical drawer open (default: true).
- `printer`: Optional specific thermal printer device name (leave empty for system default).
- `kasir`: Optional cashier operator name (e.g. 'Candana'). Defaults to the active paired cashier user.
