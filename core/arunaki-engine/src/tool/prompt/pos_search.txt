Search for product catalog items in the local ArunakiZen POS retail system.

Capabilities:
- Searches across product names, unique SKU codes, categories, and scanned barcode numbers.
- Returns unit selling prices, wholesale prices, current store stock levels, and unit of measurement (e.g. PCS, PACK).
- SUPPORTS BATCH SEARCH via `queries: [...]`: pass an array of product queries to lookup all items concurrently in 1 call!

When to use:
- The user asks for product stock, availability, or pricing (e.g. "check shirt stock", "find DTF item", "uniform price").
- Before creating a sales order. For multi-item orders, ALWAYS use batch `queries` array to resolve all items in a single shot.

Guidelines:
- If the search query is broad, return the top matching items.
- If an exact query returns 0 items, the tool automatically detects typos and returns `suggestions`.
- NEVER substitute missing or ambiguous items with another product code without confirming with the user first via the `question` tool!
- Present product code, name, unit price, and available stock clearly to the user.
